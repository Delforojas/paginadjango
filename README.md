# Proyecto Web Empresarial del curso de Django.

Este proyecto es una aplicación web desarrollada con Django que combina múltiples apps modulares (como Core, Services, Blog, Social, Pages y Contact) para ofrecer un sitio empresarial completamente funcional, extensible y personalizable.

## 📁 Estructura del Proyecto

- **Core**: App base donde se configura la estructura inicial del sitio.
- **Services**: Muestra los servicios ofrecidos por la empresa.
- **Blog**: Permite publicar artículos y gestionar relaciones entre modelos.
- **Social**: Añade enlaces a redes sociales.
- **Pages**: Gestiona páginas internas con edición desde el admin.
- **Contact**: Incluye formulario de contacto con validación y envío de correos.

## 🚀 Funcionalidades destacadas

- 🌐 Diseño empresarial responsivo.
- 🔄 Integración del frontend y backend con organización de URLs.
- 📌 Resaltado dinámico de la sección actual del menú.
- 🛠 Personalización avanzada del panel de administración (4 fases).
- 🧩 Uso de template tags propios para reutilización de lógica en plantillas.
- 📨 Formulario de contacto funcional con validación y envío de emails.
- 🔄 Procesadores de contexto para pasar variables globales a todas las plantillas.

## 🧪 Prácticas y soluciones

A lo largo del desarrollo, se integraron prácticas guiadas y soluciones para:

- Preparar apps con modelos, vistas, templates y panel admin.
- Fusionar correctamente frontend y backend.
- Configurar relaciones entre modelos en el blog.
- Personalizar el admin para hacerlo más intuitivo y visualmente profesional.

## 💡 Tecnologías utilizadas

- **Python 3.x**
- **Django**
- **HTML5, CSS3**
- **Bootstrap (opcional)**
- **SQLite / PostgreSQL / MySQL (según configuración)**
